University Management System built using C# Windows Forms and SQL Server.

The system helps manage university operations through a simple desktop interface.

Features:

Student management
Staff management
Login system with authentication
Add, update, delete, and search functions
Automatic ID generation
SQL Server database integration
Data display using DataGridView
Object-Oriented Programming concepts
Clean UI using Windows Forms

Technologies Used:

C#
.NET Framework
Windows Forms
SQL Server
ADO.NET

This project was developed as a practical university management system to improve database handling, desktop application development, and backend integration skills.
